## Project Overview

This is the **CAEP Session Presented** event transmitter for SGNL's CAEP Hub. It transmits Security Event Tokens (SET) per the [OpenID CAEP 1.0 Final specification](https://openid.net/specs/openid-caep-1_0-final.html).

## Event Type

- **URI:** `https://schemas.openid.net/secevent/caep/event-type/session-presented`
- **Required fields:** None (beyond subject/audience)
- **Optional fields:** `fp_ua`, `ext_id`, `event_timestamp`, `initiating_entity`, `reason_admin`, `reason_user`

## Repository Structure

- `src/script.mjs` - Main implementation (invoke, error, halt handlers)
- `metadata.yaml` - Action schema (inputs, outputs, secrets, environment)
- `tests/script.test.js` - Jest unit tests with ESM mocking
- `dist/index.js` - Built bundle (committed, generated by rollup)
- `scripts/dev-runner.js` - Local development runner with mock context

## Development Commands

```bash
npm test          # Run tests (Jest with --experimental-vm-modules)
npm run build     # Bundle with rollup + generate license file
npm run lint      # ESLint
npm run validate  # Validate metadata.yaml against schema
npm run dev       # Run locally with mock params
```

## Key Patterns

- Uses `@sgnl-actions/utils` for `signSET`, `getBaseURL`, `getAuthorizationHeader`
- Uses `@sgnl-ai/set-transmitter` for `transmitSET`
- `parseReason()` auto-wraps plain strings as i18n objects (`{"en": value}`) per CAEP spec
- `initiating_entity` is enum-validated in metadata.yaml
- `event_timestamp` accepts optional override (defaults to `Date.now()`)
- Tests use `jest.unstable_mockModule()` + dynamic `await import()` for ESM mocking
